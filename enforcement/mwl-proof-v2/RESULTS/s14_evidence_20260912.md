## 1. Worker cannot write a root-owned file (kernel permission wall)

```

```

## 2. Worker cannot become admin (sudo requires an operator password)

```
sudo mkdir -p <test-root>  →  "sudo: a password is required"  (worker has none)
```

The worker process cannot elevate to root. Only the operator (Eric) holds the
password. This is the operator/worker privilege boundary, demonstrated.
