## CARD 5.1 — one card per task (BUILD)

```
For every task in docs/MINED_TASKS.md write docs/cards/<id>.md:

  TASK / TYPE (INVESTIGATE or BUILD) / WHY / DO / PROOF / EXPECT / SCOPE / STOP

A task nobody has investigated gets an INVESTIGATE card, never a BUILD card.
PROOF must be a command I can run and read. "Tests pass" is not a proof.

PROOF: ls docs/cards/ | wc -l, compared to the task count. Then paste three
cards at random in full.
```
